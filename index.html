🌐 Native Web Storage

Direct browser interfaces for localized data persistence.

🍪

Cookie

Ultra-lightweight data (< 4KB) exchanged via HTTP headers. Best for session tokens and simple flags.

⏱️

SessionStorage

Volatile key-value storage tied to the current tab. Fast, synchronous, and automatically cleared on closure.

💾

LocalStorage

Persistent key-value storage with a simple API. Limited to ~5MB-10MB and synchronous in nature.

🛡️

Cache API

Asynchronous storage for Request/Response pairs. Ideal for offline assets and large binary payloads.

🗂️

IndexedDB

The standard for client-side structured data. Supports transactions, indexes, and large binary blobs.

📂

OPFS

Origin Private File System provides high-speed, direct file I/O within a sandboxed origin environment.

📦 Wrapper Libraries

Abstractions that simplify complex storage APIs and ensure compatibility.

🛠️

store.js

A zero-dependency wrapper that picks the best storage (starts with LocalStorage) with a clean, unified API.

💎

SQLite (WASM)

The legendary relational database running via WebAssembly. Provides full SQL capabilities on top of OPFS.

⛓️

localForage

An asynchronous fallback library (IDB -> WebSQL -> LocalStorage) using a Simple LocalStorage-like API.

⚡

Dexie.js

Optimized IndexedDB wrapper providing a fluent API, robust transactions, and easy schema management.

🐶

PouchDB

An offline-first browser DB that can automatically sync with CouchDB and other remote instances.

🗜️ Compression Engines

Algorithms used to reduce payload size before storage or transmission.

📦

ZIP

Widely used format balancing compression ratio and speed. Great for multi-file payloads.

🌪️

Gzip

Native browser compression stream using the DEFLATE algorithm. Highly efficient for text data.

💨

Deflate

Lower-level algorithm used by ZIP and Gzip, optimized for speed and memory efficiency.

🍞

Brotli

Modern algorithm by Google offering superior compression ratios for web assets compared to Gzip.

🦖

zstd

Real-time compression algorithm from Meta. Provides high ratios at blistering speeds via WASM.
